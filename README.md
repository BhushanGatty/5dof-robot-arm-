This is a 5-Degrees-of-Freedom (5-DOF) robotic arm designed and assembled in **SolidWorks 2025**. This model was created for robotics applications, CAD practice, assembly visualization, and educational purposes.

## Specifications
- **DOF:** 5 Degrees of Freedom
- **Actuators:** 3x Standard Servos, 2x Micro Servos
